# 开源项目研究与实践库

> 对值得长期研究、使用或跟踪的开源项目进行筛选、分析、实践和归档。

本仓库**不限定 AI 项目**。AI 项目只是项目类型之一；凡是有明确使用价值、技术参考价值、独特功能价值或长期跟踪价值的开源项目，都可能被收录。

## 收录原则

不是每个提交给研究的项目都会进入仓库。项目先研究、后评估、再决定是否收录。

| 评估结果 | 处理方式 |
|---|---|
| 推荐收录 | 建立完整项目档案，纳入目录和索引 |
| 暂不收录 | 保留必要的评估结论，不进入正式项目目录；条件变化后可复评 |
| 不推荐收录 | 说明主要原因，不建立正式档案 |

重点考察：实际用途与独特性、维护活跃度、文档与可安装性、兼容性、许可证、权限与安全风险、学习/技术参考价值，以及与已有项目的重复程度。

## 项目档案标准

正式收录的项目尽可能包含：

1. 项目定位、背景、官方链接、许可证与项目类型标签
2. 核心功能、工作原理和技术架构
3. 环境要求、安装步骤、配置方法
4. 从入门到典型场景的实际使用教程
5. 与 CLI、API、MCP、Skill、插件或其他平台的集成方式（如适用）
6. 适用场景、优缺点、限制、安全与维护风险
7. 项目成熟度和综合评估
8. 若适合封装：最合适的封装形态、架构、安装/接入/配置/使用步骤、权限要求及现实可行性
9. 信息核验日期与官方参考资料

AI 项目会额外标记为 **AI 项目**，但不因此获得自动收录资格。

## 目录

- `projects/`：正式收录的项目档案，按主要用途分类
- `templates/`：项目档案模板
- `standards/`：收录、研究和文档规范
- `plugin-development/`：值得进一步封装或集成的候选项目及方案

## 评估状态

- `recommended`：推荐收录
- `watch`：暂不收录，等待观察或补充验证
- `not-recommended`：不推荐收录
- `archived`：已停止维护或仅作为历史参考

## 研究与维护原则

- 优先使用项目官方 README、文档、源码、Release、Issue 和安全公告。
- 明确区分官方事实、实测结果和分析判断。
- 命令、版本、配置项与兼容性应标注核验时间；易变信息定期复核。
- 不把“有 MCP/API/CLI”直接等同于“能接入 ChatGPT”；必须说明宿主平台、传输方式、网络可达性和权限条件。
- 不为凑数量而收录；不为了封装而封装。
- 不复制上游项目的大段文档，保留必要摘要并链接官方来源。

## 许可证与免责声明

本仓库主要保存研究笔记、操作说明和链接。各项目仍遵循其自身许可证；使用前应阅读上游许可证、隐私政策和安全说明。文档中的操作步骤以注明的版本和环境为准。
