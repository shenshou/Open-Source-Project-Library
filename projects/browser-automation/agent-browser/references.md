## 核验要点

- GitHub README / Release：确认项目定位、许可证、版本和平台支持。
- Installation：确认 Node/npm 安装方式、浏览器下载、系统依赖和诊断命令。
- Commands：确认 CLI 命令与参数。
- Configuration：确认配置文件、环境变量和默认行为。
- Security：确认 Auth Vault、域名白名单、动作策略、内容边界及其限制。
- MCP：确认当前版本 MCP 工具、传输方式和宿主配置。
