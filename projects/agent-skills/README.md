# Agent Skills 与 AI 工作流

本分类收录面向 AI Agent 的可复用技能、工程流程和任务编排规范。它们通常以 Skill 指令文件、插件包或 Agent 配置的形式交付，而不是独立应用程序。

## 正式收录项目

| 项目 | 定位 | 收录状态 |
|---|---|---|
| [mattpocock/skills](./mattpocock-skills/README.md) | 面向真实软件工程的 Agent Skills 集合，覆盖需求澄清、规格、任务拆分、实现、测试、调试、代码审查和协作流程 | recommended |

## 分类边界

- **Agent Skills**：给 Agent 提供可复用的任务流程、判断规则和上下文知识。
- **Agent 插件**：将一组 Skills 以宿主平台可安装、可管理的插件形态分发。
- **独立 Agent / 自动化平台**：若项目本身提供独立运行时、任务执行平台或完整应用，应按其主要用途另行分类。
- 本分类不意味着所有 Skill 都适合所有 Agent，也不代表它们能直接安装到 ChatGPT 网页版。

## 收录原则

先评估项目的实际可用性、维护情况、许可证、宿主兼容性、外部工具依赖和安全边界，再决定是否正式收录。Beta、实验性和已弃用的子项目应与稳定发布内容分开记录。
